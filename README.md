# Gap总控台

> 一个面向 Gap 期人群的网页版生活系统。离开职场的外部结构后，人在家容易全面崩盘——作息颠倒、越躺越累、吃饭清洁收拾全做不到。这个工具不催你"自律"，而是用低压力、可摆烂、有正反馈的方式，帮人把日子稳住。

**在线体验**：https://fifteen-15-z.github.io/gap-control-center/
（手机浏览器打开 → 分享 → 添加到主屏幕，即变全屏 APP）

---

## 适合谁

- 处于 Gap / 失业 / 长期居家状态，缺乏外部时间表约束的人
- 执行力偏弱、有 ADHD 倾向，普通效率工具用两天就弃的人
- 一个人生活、容易没正反馈，需要"勾到一个就是胜利"的轻量记录

## 核心设计

设计信念：**少依赖意志力，多依赖视觉锚点和低摩擦记录；阶段不是开关，是滑块。**

| 设计点 | 怎么落地 |
|---|---|
| 不让人崩溃 | 「今日能量状态」三档（满血 / 普通 / 低能耗），低能耗日自动豁免清洁+整理，不红色施压 |
| 允许摆烂 | 「今天休息日」彻底不打卡；和「低能耗」是两档不同状态 |
| 正反馈 | 每勾一项 +1 能量币，攒够兑换自定义奖励（外卖 / 电影 / 想要的小东西） |
| 视觉锚点 | 顶部「今天进度」圆环 + 实时时钟 + 按时段给的建议，治时间盲 |
| 不凭空消失 | 没完成的作息自动滚成红色逾期 + 一键补卡 |
| 低压力文案 | 用「勾到一个就是胜利」代替密密麻麻的待办 |

## 功能模块

- **日常**：今天要处理（置顶）· 核心作息 · 生活例行（吃饭 / 照顾猫 / 个人清洁 / 房间整理）· 今日三件小事 · 身心签到 · 能量币奖励银行
- **恢复**：作息周报 · 体重 / 减重折线 · 运动打卡 · 心情精力趋势 · 精力热力图 · 恢复里程碑
- **精神**：看书 / 剧 / 电影 / 演唱会 / 展览记录 + 评分 + 一句话感想
- **玩乐**：Gap 旅行 / 现场回忆墙（带图）+ 时间线
- **机会**：看机会看板（灵感 → Offer）+ 学习提升记录
- **财务**：本月收支 + 预算进度 + 支出分类饼图 + 蓄水池（还能撑几个月）

## 怎么用

1. 打开在线链接，建议「添加到主屏幕」当 APP 用
2. 数据存在你自己的浏览器本地，不联网也能用，不上传任何服务器
3. 顶部「导出备份」随时存成 JSON，换设备时「导入恢复」

## 技术实现

- 单文件网页应用，全部 CSS / JS / SVG 图标内联，**零外部依赖、离线可用**
- 图表（进度环 / 柱状 / 饼 / 折线 / 热力）均为手写 SVG，不引任何图表库
- 数据存浏览器 `localStorage`，支持 JSON 导出 / 导入
- 代码分层见 `index.html` 顶部注释（工具 / 资源 / 数据 / 图表 / 视图 / 交互）

## 隐私

页面是公开链接，但只暴露界面外壳——你的数据存在各自浏览器本地，陌生人打开是空壳。健康 / 财务数据不出本机。
