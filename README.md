# Gap总控台 · 一个面向 Gap 期人群的生活系统（AI 协作作品集）

> 访谈了几位被裁后进入 Gap 期的朋友，发现一个共性痛点：离开职场的外部结构后，在家容易生活全面崩盘——作息颠倒、越躺越累、吃饭/清洁/收拾全做不到。
> 于是我用 AI 从零搭了这套「生活总控台」，作为解决这类问题的产品原型，自己跑需求、AI 落地实现，十几轮对话迭代出来的成品。

## 这是什么

一套**单文件网页应用**，专门给「无外部时间表约束、在家容易崩」的人用。不是效率工具，是「不让人放弃」的工具。

核心设计信念：**少依赖意志力，多依赖视觉锚点和低摩擦记录；阶段不是开关，是滑块。**

## 用户洞察（来自早期访谈）

- 在家无结构 → 作息颠倒、越躺越累
- 执行力偏弱（部分有 ADHD 倾向） → 吃饭/清洁/收拾房间全做不到
- 一个人 Gap → 心情差、没正反馈、容易崩
- 这类人群最需要的不是密密麻麻的待办，而是**低压力、可摆烂、有正反馈**的设计

## 设计方法论（作品集重点）

| 原则 | 落地 |
|---|---|
| **不让人崩溃** | 「今日能量状态」三档（满血/普通/低能耗），低能耗日自动豁免清洁+整理，不红色施压 |
| **允许摆烂** | 「今天休息日」彻底不打卡；和「低能耗」是两档 |
| **正反馈钩子** | 每勾一项 +1 能量币，攒够兑换奖励（外卖/电影/想要的小东西），自定义奖励银行 |
| **视觉锚点** | 顶部「今天进度」圆环 + 实时时钟 + 按时段给的建议（治时间盲） |
| **昨天不凭空消失** | 没完成的作息自动滚成红色逾期 + 一键补卡 |
| **低压力文案** | 「勾到一个就是胜利」「扔 1 样垃圾太轻了，换成整理一个台面」 |

## 模块地图（6 个 Tab）

- **日常**：今天要处理（置顶）· 核心作息 · 生活例行（吃饭/照顾猫/个人清洁/房间整理）· 今日三件小事 · 身心签到 · 今日能量状态 · 能量币奖励银行
- **恢复**：作息周报 · 体重/减重折线 · 运动打卡（跳舞/健身/骑车…）· 心情精力趋势 · 精力热力图 · 恢复里程碑
- **精神**：看书/剧/电影/演唱会/展览记录 + 评分 + 一句话感想
- **玩乐**：Gap 旅行/现场回忆墙（带图） + 时间线
- **机会**：看机会看板（灵感→Offer 6 列） + 学习提升记录
- **财务**：本月收支 + 预算进度 + 支出分类饼图 + 蓄水池（还能撑几个月）

## 技术亮点

- **单文件、零外部依赖**：全部 CSS/JS/SVG 图标内联，无 CDN、无框架，离线可用
- **手写 SVG 图表**：进度环、柱状图、饼图、折线图、热力图全部原生绘制
- **本地优先存储**：数据存浏览器 `localStorage`，隐私不出本机；支持 JSON 导出/导入迁移
- **PWA 体验**：添加到主屏幕即全屏原生感，含内联 SVG favicon
- **渐进式迭代**：每次只加/改 1 个模块，老数据用 key 隔离、迁移不丢

## 迭代记录（AI 协作过程）

这项目最有价值的不是代码，是**产品迭代轨迹**：

1. 先明确人群与三阶段框架（玩乐→休息→看机会，滑块非开关）
2. 合并成单工作台，而非摊三个
3. 支持自定义 Gap 起点日期与阶段命名，贴合真实时间线
4. 拆出吃饭/照顾猫/房间整理（融入式，不加 Tab）
5. 加「精神」Tab 记书影音
6. 加个人清洁 + 细化整理 + 防崩溃三机制（能量状态/能量币/摆烂）
7. 命名「Gap总控台」+ 图标

每个改动都来自真实使用反馈，而非预先规划——这正是 AI 辅助个人产品最爽的地方。
